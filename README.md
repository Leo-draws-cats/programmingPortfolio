# Calculator
## Overview
OOP Calculator using Processing for graphics and Java for computer Programming. 
## Current Status
Working:
- Number buttons
- The buttons slightly change colors when you hover over them
- The decimal button doesn't allow multiple decimals

Still in progress:
- Most if not all operator buttons 

## How to Run
Built with Processing.
Processing version: 4.0.1

## Controls
Mouse:
Hover over the desired button then click it

Keyboard:
The "1" key works and that's it

## Project Files
Calculator.pde
Button.pde

## Testing
The "^" "^2" "?" "CE" buttons all do nothing ;-;
Instead of making the number on the display negative the "-x" button simply works as a secondary subtraction button. It's possible to get the desired outcome by clicking either the subtraction or negative button before you click the number you want, then click "=" but that's a lot and not the way anyone would use it.

## Next Step
My first goal is to fix the "CE" (clear everything) button since it would be the most useful in testing.
